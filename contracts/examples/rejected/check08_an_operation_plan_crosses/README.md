# check 8 — an operation plan does not cross

The payload is a focus search with no goal: it finds a plane and measures
nothing about the sample. It reaches VALIDATED like any plan, and the envelope
calls that a plan completion, so every other gate is satisfied -- the
answerability verdict is the one the tables give, the ledger and the turn are
in place. What is wrong is that the other side has nothing to answer.

**Why now.** With the focus search in the workflow, every microscope session
starts with one of these, so finished operation plans become the most common
finished plan on that side. Without the rule, the first one wrapped as a round
would be held for a person who has nothing to decide.

Watched failing: with the new branch in check 8 switched off, this group
passes every check.
