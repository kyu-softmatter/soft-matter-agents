- **PASS.** HOOMD 7.2.0 CPU in WSL Ubuntu-24.04 via `pixi run -e sim --frozen`.
  One Brownian particle, kT = 1, input D = 0.49 um^2/s (computed, Stokes-Einstein for
  a 1 um sphere in water at 25 C with viscosity 0.89 mPa s assumed; not measured),
  dt = 1 ms, 10^6 steps = 1000 s simulated, wall time 0.8 s.
- D recovered from the mean squared displacement of one trajectory (computed from
  the run): 0.4902 / 0.4874 / 0.4915 / 0.4838 um^2/s at lags 0.01 / 0.1 / 1 / 10 s,
  each within 1 sigma of 0.49; per-axis spreading and zero drift agree.
- **Finding:** the engine's random kicks are uniformly distributed, not Gaussian
  (kurtosis of n-step displacements 1.799 / 2.398 / 2.762 / 2.894 at n = 1 / 2 / 5 / 10;
  uniform predicts 1.800 / 2.400 / 2.760 / 2.880, Gaussian 3). Diffusion and anything
  over tens of steps are right; single-step or few-step displacement statistics are not
  Gaussian.
- **What did not work:** from Git Bash without `MSYS_NO_PATHCONV=1`, `wsl.exe` fails
  with a path-not-found error, and a pipe after it still reports exit 0. PowerShell, or
  Git Bash with that variable set, works.
