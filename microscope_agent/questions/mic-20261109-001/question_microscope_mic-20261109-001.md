# mic-20261109-001 -- how drag on a trapped bead depends on height above the glass

Asked by the person in the bench session on 2026-11-09 (committed verbatim, `docs/ideas/20261109-scope.md`, I-20261109-scope-01).

- **Purpose:** characterize -- "Quantify the wall effect".
- **Accuracy:** about 10 %, relative, on the drag at each height. That is a stated accuracy, so the question runs in confirm mode.
- **If goals conflict:** the number of heights gives way first.
- **Quantity named:** the bead's mean displacement from the trap centre under steady flow, from which drag follows (stiffness times offset over speed).
- **Preference kept:** move the stage, hold the trap.

**Where it stands: refused at the first design stage.** The instrument's capability table does not list this displacement as something any configuration can produce. Its own note says why: nothing on disk showed the piezo stage moving at a controlled speed. Today's bench run suggests it can, but that evidence is not in the repository, and the table is not this agent's to change. See `refusal_microscope_mic-20261109-001_s30.json`.
