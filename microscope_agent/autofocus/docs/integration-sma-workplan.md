### 2.3 Three data flows

**Actions only through a plan.** Screen/assistant → `hw_port.plan_draft(op, args)` → `<config_dir>/plans/drafts/<draft_id>.json` (`status: DRAFT`, `drafted_by: <person_id>`, `author: human`, `source: person|envelope` on every number; envelope limits read-only from `envelope/safety.json`; the draft is refused if a key is missing; a number the assistant (model) chose cannot enter `numbers[]`, and a person must type it on the screen or accept it field by field — this prevents E6 laundering) → the autofocus seat (or a person) copies it **under its own name** into SMA `questions/<qid>/plan_*.json` → a person writes `approvals/appr-<qid>-r<N>.json` (the console shows the JSON and copies it to the clipboard, nothing more; there is no save button) → a person runs `operator.run` in pixi `mic` → `orchestrator.dispatch` (allow list, interlocks, exceptions) → `runs/<run_id>/log.json` (and `events.jsonl` after G-13) → the console's `SmaFilesPort` polls `runs/` and the drafts folder → shows approval state, progress "as of <time>", and verdicts. Abort is disabled in SMA mode until G-13's loopback socket exists: "stop it at the instrument or in the operator terminal".

**Records go to `runs/` through de-identification.** Engine records → `D:\AutoFocus\records` (`bench`, `backend_kind`, `sma_run_id`, `sma_runs[]` added to the session) → the session screen's "Export" (ids replaced through `people.json`, `redact.py` refuses the whole session if even one residue remains, refused unless `bench: true`) → `D:\AutoFocus\outbox\<run_id>\console.session.json`, `console.manifest.json`, `console.log.session.jsonl`, `console.records.<op>.jsonl`, `console.export.json` (per-file sha256, `runs[]`, `session_hash`) → an SMA seat checks the hashes, copies them into `runs/<run_id>/` next to `log.json`, and commits naming each file (G-08) → the librarian reads only runs that have a `log.json` and `bench: true`. `console.*` and the verdict events **do not self-report a grade; they carry only the source (`measured:<run_id>`, `computed:<formula_id>`, `prior_run:dino-autofocus@<sha>`)**; the SMA side derives the grade from the source (L-04). A run folder without `log.json` trips check 15 (the check that a run folder must hold the operator's log), so the SMA run has to exist first.

**Knowledge goes to the librarian.** Question cards in `docs/librarian-handoff.md` → the user answers the 20 cards needed before the copy (16 whose numbers leave the flat files + 4 conflicts) → SMA `findings/<seat>-<date>.json` (document_fact / person_statement / unmeasured) → the librarian reads the cited paths **at the named commit** and enters them at E3 or below → KB publication → `envelope/snapshot.json`. dino is already public, so the source the librarian reads is **the public URL and the commit sha** (`prior_run:dino-autofocus@<sha>`), and a line naming that as an allowed source goes into G-02 (e).
